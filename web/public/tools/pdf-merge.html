Cara memakai Gabung PDF (PDF Merge)

  1. Pilih atau seret beberapa file PDF, JPG, atau PNG.
  2. Atur urutan dengan menyeret atau tombol panah.
  3. Isi rentang halaman bila hanya perlu sebagian, misalnya 1-3, 5.
  4. Klik Gabungkan & Download.

Pertanyaan umum

Bisa menggabungkan PDF dengan foto KTP atau ijazah?

Bisa. Foto JPG/PNG otomatis dijadikan halaman PDF berukuran A4.

Apakah dokumen saya aman?

Ya. Penggabungan dilakukan di browser Anda; dokumen tidak di-upload ke server mana pun.

Bisa ambil halaman tertentu saja?

Bisa. Tulis rentang seperti 1-3, 5, 8- pada setiap file PDF.

Ada batas ukuran file?

Hingga 100 MB per file, tergantung memori perangkat Anda.
